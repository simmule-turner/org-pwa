#+TITLE: Holidays
#+STARTUP: content

The holidays the Agenda, the diary and *List holidays…* show are Emacs's =calendar-holidays=, put together from groups. This file shows which are on, how to turn every one on, how to switch some off, and how to add your own; the results are what Emacs 29.3 listed for 2026 (time zone America/New_York), and a test checks the app lists the same.

* How to try an example
Copy the Lisp into Settings → Advanced → *Lisp init*, then open the palette and run *List holidays…* with 2026 as both years. The same text works in an Emacs init file: put it where it runs before the calendar loads, because Emacs builds =calendar-holidays= from the group variables once, when it loads. (Setting =calendar-holidays= itself works at any time.)

Holidays reach the Agenda through the diary: with =org-agenda-include-diary= on they are the "Diary:" rows. =diary-show-holidays-flag= set to =nil= leaves them out.

* What is on, and what is not
Seven groups come with Emacs, and two more are yours. All are on, except the extra entries each of five groups holds back behind a flag:

| Variable                      | Holds                                              | Flag for the extra entries                  |
|-------------------------------+----------------------------------------------------+---------------------------------------------|
| =holiday-general-holidays=    | United States public days and observances          |                                             |
| =holiday-christian-holidays=  | Ash Wednesday, Good Friday, Easter, Christmas      | =calendar-christian-all-holidays-flag=      |
| =holiday-hebrew-holidays=     | the festivals and Hanukkah                         | =calendar-hebrew-all-holidays-flag=         |
| =holiday-islamic-holidays=    | Islamic New Year, the start of Ramadan             | =calendar-islamic-all-holidays-flag=        |
| =holiday-bahai-holidays=      | the Bahá’í festivals and three days of Ridvan      | =calendar-bahai-all-holidays-flag=          |
| =holiday-oriental-holidays=   | Chinese New Year                                   | =calendar-chinese-all-holidays-flag=        |
| =holiday-solar-holidays=      | equinoxes, solstices, daylight saving time changes |                                             |
| =holiday-local-holidays=      | yours, for where you live (empty)                  |                                             |
| =holiday-other-holidays=      | yours, any others (empty)                          |                                             |

Every flag is =nil= until you set it. The general group is American; "Replace a group" below changes it.

** What is on by default
With no Lisp init at all, Emacs lists these (2026, time zone America/New_York). Every ~calendar-*-all-holidays-flag~ is off.

* Switch things off
** Switch one group off
Set its variable to ~nil~. The sun-related group holds the equinoxes, solstices and the days daylight saving time starts and ends.

#+begin_src emacs-lisp

#+end_src

** Remove one entry from a group
~remove~ takes the entry, written as it stands in the group, and the group.

#+begin_src emacs-lisp
(setq holiday-general-holidays
      (remove '(holiday-fixed 2 2 "Groundhog Day") holiday-general-holidays))
#+end_src

Compared with the default list for 2026 (~+~ is added, ~-~ is gone):

#+begin_example
- Monday, February 2, 2026: Groundhog Day
#+end_example

** Remove several entries
~remove~ calls nest. An entry is matched as written, quotes and spaces aside, so copy it from the group (the lists are in [[https://git.savannah.gnu.org/cgit/emacs.git/tree/lisp/calendar/holidays.el][holidays.el]]).

#+begin_src emacs-lisp
(setq holiday-general-holidays
      (remove '(holiday-fixed 2 2 "Groundhog Day")
              (remove '(holiday-fixed 4 1 "April Fools' Day")
                      (remove '(holiday-float 10 1 2 "Columbus Day")
                              holiday-general-holidays))))
#+end_src

Compared with the default list for 2026 (~+~ is added, ~-~ is gone):

#+begin_example
- Monday, February 2, 2026: Groundhog Day
- Wednesday, April 1, 2026: April Fools' Day
- Monday, October 12, 2026: Columbus Day
#+end_example

** Keep only your own
Every group off, and the list is yours. ~holiday-local-holidays~ is for holidays of where you live, ~holiday-other-holidays~ for any others; both are always part of the list.

#+begin_src emacs-lisp
(setq holiday-general-holidays nil
      holiday-christian-holidays nil
      holiday-hebrew-holidays nil
      holiday-islamic-holidays nil
      holiday-bahai-holidays nil
      holiday-oriental-holidays nil
      holiday-solar-holidays nil)
(setq holiday-local-holidays
      '((holiday-fixed 3 14 "Pi Day")
        (holiday-easter-etc 1 "Easter Monday")))
(setq holiday-other-holidays
      '((holiday-fixed 12 26 "Boxing Day")))
#+end_src

** Name the list yourself
~calendar-holidays~ is what Emacs uses; the groups are only how it is first put together. Setting it directly (after ~(require 'holidays)~, so the group variables exist) picks the groups you want. Here, the Christian and Islamic groups and nothing else:

#+begin_src emacs-lisp
(require 'holidays)
(setq calendar-holidays
      (append holiday-christian-holidays
              holiday-islamic-holidays))
#+end_src

* Add your own
The forms Emacs gives you, each in ~holiday-local-holidays~ (or ~holiday-other-holidays~). The manual describes them in [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Holidays.html][Holidays]] and [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Advanced-Calendar_002fDiary-Usage.html][Advanced Calendar/Diary Usage]]; the source is [[https://git.savannah.gnu.org/cgit/emacs.git/tree/lisp/calendar/holidays.el][holidays.el]].

** Add a fixed date: holiday-fixed
~(holiday-fixed MONTH DAY "NAME")~: the same date every year.

#+begin_src emacs-lisp
(setq holiday-local-holidays
      '((holiday-fixed 3 14 "Pi Day")
        (holiday-fixed 6 19 "Juneteenth")))
#+end_src

Compared with the default list for 2026 (~+~ is added, ~-~ is gone):

#+begin_example
+ Saturday, March 14, 2026: Pi Day
+ Friday, June 19, 2026: Juneteenth
#+end_example

** Add "the Nth weekday": holiday-float
~(holiday-float MONTH DAYNAME N "NAME" [DAY])~. DAYNAME is 0 for Sunday to 6 for Saturday; N counts from the start of the month, or from its end when negative. A DAY makes it the Nth weekday on or after that day: the Tuesday after the first Monday of November is the first Tuesday on or after November 2.

#+begin_src emacs-lisp
(setq holiday-local-holidays
      '((holiday-float 11 2 1 "Election Day" 2)
        (holiday-float 4 5 -1 "Arbor Day")))
#+end_src

Compared with the default list for 2026 (~+~ is added, ~-~ is gone):

#+begin_example
+ Friday, April 24, 2026: Arbor Day
+ Tuesday, November 3, 2026: Election Day
#+end_example

** Add a day counted from Easter: holiday-easter-etc

#+begin_src emacs-lisp
(setq holiday-local-holidays
      '((holiday-easter-etc 1 "Easter Monday")
        (holiday-easter-etc 7 "Low Sunday")))
#+end_src

+ Sunday, April 12, 2026: Low Sunday
#+end_example

** Add a computed date: holiday-sexp
~(holiday-sexp EXPR "NAME")~: EXPR gives the date in the variable ~year~ as ~(MONTH DAY YEAR)~, or ~nil~ when there is no holiday that year.

#+begin_src emacs-lisp
(setq holiday-local-holidays
      '((holiday-sexp '(if (zerop (% year 4)) (list 2 29 year)) "Leap Day")

#+end_src

#+begin_example

#+end_example
