* Why Org
** Plain text, rich result
- Headings are slides
- Lists build up on request
- *Bold text* is highlighted with \alert
- Math works inline, \(e^{i\pi} + 1 = 0\), and in display form
** Overlays

:END:

* Code and math
** A source block
#+begin_src python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
#+end_src

*** Theorem
