#+TITLE: Capture templates in Lisp
#+STARTUP: overview

Put this in the Lisp init (~org-xx-lisp-init~). Each template is the form Emacs reads. =capture-functions.org= has more, with the file before and after as Emacs files it: the template for a shared web page or text (=w=), lists, a table row and a journal, and templates that use a function. Capture keywords are Emacs's own: =:prepend=, =:empty-lines=, =:table-line-pos=, =:tree-type=, =:prepare-finalize=, =:jump-to-captured=. =:jump-to-captured t= opens the new text after the capture; without it the screen stays where it was.

* Entries, lists and rows
Targets name a place that exists: =file+headline= and =file+olp= need the headings to be in the file (the Capture panel here makes a missing one, where Emacs reports "Heading not found"). For a heading that changes, such as the current month, a target function finds or makes it; see =capture-functions.org=.
#+BEGIN_SRC emacs-lisp
(setq org-capture-templates
  '(("m" "Meeting" entry (file+headline "notes.org" "Meetings")
     "* %^{Title} :meeting:\n%U\n%?")
    ("l" "Log line" item (file+olp "home.org" "Journal" "Log")
     "%<%H:%M> - %?" :prepend t)
    ("k" "Check item" checkitem (file+olp "home.org" "Journal" "Log")
     "%?")
    ("r" "Row" table-line (file+olp "home.org" "Tracking")
     "| @# | %<%Y-%m-%d> | %<%H%M> ||" :jump-to-captured t)))
#+END_SRC

* Blank lines and table rows
=:empty-lines N= leaves N blank lines before and after the new text (=:empty-lines-before= and =:empty-lines-after= set each side). =:table-line-pos "I+1"= puts a row on the line after the first rule. A table a capture starts has an empty header row and a rule, as in Emacs.
#+BEGIN_SRC emacs-lisp
(add-to-list 'org-capture-templates
  '("e" "Expense" table-line (file+headline "money.org" "Expenses")
    "| %<%Y-%m-%d> | %^{What} | %^{Amount} |" :table-line-pos "I+1"))
(add-to-list 'org-capture-templates
  '("s" "Task" entry (file+headline "tasks.org" "Inbox")
    "* TODO %?" :empty-lines 1))
#+END_SRC

* One more template
#+BEGIN_SRC emacs-lisp
(add-to-list 'org-capture-templates
  '("n" "Note" plain (file "inbox.org") "* %?"))
#+END_SRC

* Under today's date
=file+olp+datetree= files a capture under the year, the month and the day, making the headings it needs; =:tree-type week= or =:tree-type month= chooses the week or month tree, and =:prepend t= puts the entry first. =file+datetree= and =file+weektree= are the older names. =capture-datetree.org= shows each with the file before and after.
#+BEGIN_SRC emacs-lisp
(add-to-list 'org-capture-templates
  '("d" "Journal" entry (file+olp+datetree "journal.org" "Journal") "* %?"))
#+END_SRC
