#+TITLE: Capture templates
#+STARTUP: showall

Capture templates for the Lisp init (=org-xx-lisp-init=, Settings > Advanced), the form Emacs reads, and what they do beyond a fixed place. Each section shows the file before, the Lisp to copy into the init, and the file after org-capture files it. The results are what Emacs 29.3 (Org 9.6.15) produced, and a test holds the app to them.

Two keywords make this possible: =(file+function "file.org" FUNCTION)= as a target, and =:prepare-finalize FUNCTION=. A function is a name, a =(lambda () ...)=, and for =:prepare-finalize= also a list of them; it runs in a text buffer as Emacs's (=point=, =re-search-forward=, =insert=, =flush-lines= ...).

* A shared web page
The template for anything shared in from another app: =entry= (Emacs does not shift the headings of =plain= text), with =:empty-lines 1=. In Emacs, =%a= is the link stored for the page and =%i= the text selected when the capture starts. In the app, sharing a web page fills them: =%a= is the page as a link, =[[address][title]]=, and =%i= the shared text, if any. A web page has a title already, so the title prompt is left blank; the note is typed at =%?=.

#+BEGIN_SRC emacs-lisp
(defun my-olp-target (names)
  "Find or create the outline path NAMES in the file and leave point on its last heading.
A heading that has to be created goes last among its siblings."
  (let ((level 1) (start (point-min)) (end (point-max)))
    (dolist (name names)
      (goto-char start)
      (if (re-search-forward (format "^\\*\\{%d\\} %s[ \t]*$" level (regexp-quote name)) end t)
          (setq start (1+ (match-end 0)))
        (goto-char end)
        (unless (bolp) (insert "\n"))
        (insert (make-string level ?*) " " name "\n")
        (setq start (point)))
      (goto-char start)
      (setq end (if (re-search-forward (format "^\\*\\{1,%d\\} " level) nil t) (match-beginning 0) (point-max)))
      (setq level (1+ level)))
    (goto-char start) (forward-line -1) (beginning-of-line)))

#+BEGIN_SRC emacs-lisp
(defun my-year-heading ()
  "Find or create the heading of this year and leave point on it."
  (let ((year (format-time-string "%Y")))
    (goto-char (point-min))
    (unless (re-search-forward (format "^\\* %s\\(?: .*\\)?$" (regexp-quote year)) nil t)
      (goto-char (point-max))
      (unless (bolp) (insert "\n"))
      (insert "* " year "\n")
      (forward-line -1))
    (beginning-of-line)))

(add-to-list 'org-capture-templates

(defun my-vcard-drop-empty ()
  "Drop the empty fields of a captured vCard, and an empty trailing tag."
  (goto-char (point-min))
  (when (re-search-forward "[ \t]+:+[ \t]*$" (line-end-position) t)
    (replace-match ""))
  (goto-char (point-min))
  (flush-lines "^[A-Za-z][A-Za-z0-9_-]*\\(;[^:\n]*\\)?:[; \t]*$"))

* Tracking
A =table-line= template whose target function finds or makes the headings =Bag=, =Health=, =Tracking= and the current month, puts the new month first, and gives it a plot line, a table and the formulas. The row is filed into that table, the formulas are worked out again, and =:jump-to-captured t= opens the table and scrolls to the new row. The file already has October; two rows are captured in November.

Emacs does not expand =@#= in a template, so the first column is a formula, =$1=@#-1= (the header row counts as a row). Emacs rejects a =#+TBLFM= line that defines =$4== twice ("Double definition"), so one formula gives the hour column.

#+BEGIN_SRC emacs-lisp
(defun my-tracking-target ()
  "Find or create Bag > Health > Tracking > this month and leave point on that heading.
A new heading goes first among its siblings; a new month also gets the plot, the table and its formulas."
  (let ((level 1) (start (point-min)) (end (point-max)))
    (dolist (name (list "🛍️ Bag - lists and notes" "❤️ Health" "🏩 Tracking" (format-time-string "%Y-%m")))
      (goto-char start)
      (if (re-search-forward (format "^\\*\\{%d\\} %s[ \t]*$" level (regexp-quote name)) end t)
          (setq start (1+ (match-end 0)))
        (goto-char start)
        (goto-char (if (re-search-forward "^\\*+ " end t) (match-beginning 0) end))
        (unless (bolp) (insert "\n"))
        (insert (make-string level ?*) " " name "\n")
        (when (= level 4)
          (insert "#+PLOT: title:\"Tracking\" ind:4 deps:1 with:points ticks:6\n|   |\n|---|\n"
                  "#+TBLFM: $1=@#-1 :: $4=if(round(trunc($3/100) + 100*($3/100 - trunc($3/100)) / 60) == 24, 0, round(trunc($3/100) + 100*($3/100 - trunc($3/100)) / 60))\n"))
        (setq start (save-excursion (re-search-backward (format "^\\*\\{%d\\} " level)) (forward-line 1) (point))))
      (goto-char start)
      (setq end (if (re-search-forward (format "^\\*\\{1,%d\\} " level) nil t) (match-beginning 0) (point-max)))
      (setq level (1+ level)))
    (goto-char start) (forward-line -1) (beginning-of-line)))

* Blank lines and table rows
=:empty-lines N= leaves N blank lines before and after the new text (=:empty-lines-before= and =:empty-lines-after= set each side). =:table-line-pos "I+1"= puts a row on the line after the first rule. A table a capture starts has an empty header row and a rule, as in Emacs.
#+BEGIN_SRC emacs-lisp
(add-to-list 'org-capture-templates
  '("e" "Expense" table-line (file+headline "money.org" "Expenses")
    "| %<%Y-%m-%d> | %^{What} | %^{Amount} |" :table-line-pos "I+1"))
(add-to-list 'org-capture-templates
  '("s" "Task" entry (file+headline "tasks.org" "Inbox")
    "* TODO %?" :empty-lines 1))

* Under today's date
=file+olp+datetree= files a capture under the year, the month and the day, making the headings it needs; =:tree-type week= or =:tree-type month= chooses the week or month tree, and =:prepend t= puts the entry first. =capture-datetree.org= shows each with the file before and after.

* Where the app differs from Emacs
=:before-finalize= runs on the text of the capture, after =:prepare-finalize=, where Emacs runs it on the whole file. =:after-finalize= runs once the entry is filed, in a buffer with no text; =:refile-targets= has no effect. =:clock-in= clocks the new entry when the capture is filed; Emacs does it when the capture buffer opens. A target function may only insert whole lines; one that changes or deletes a line is refused with a message and nothing is filed. A =file+function= template of type =item=, =checkitem= or =table-line= needs the function to leave point on a heading. In the buffer of a function, markers and text properties are not available, the regexp operator ~\=~ never matches, and a search with a bound treats ~$~ and ~\'~ at the bound as the end of the text. The =github:= prefix of a file name is the app's own.
