#+TITLE: Org Crypt
#+STARTUP: showall

Org Crypt keeps the text of an entry secret in the file: it is replaced by a block of =-----BEGIN PGP MESSAGE-----= text that Emacs (=org-decrypt-entry=) and gpg can open too. The heading, its tags and its properties stay readable. Everything below them, sub-headings included, is encrypted.

Open the command palette and choose:
- *Encrypt entry* / *Decrypt entry* (=org-encrypt-entry=, =org-decrypt-entry=): the entry you are on.
- *Encrypt all crypt entries* / *Decrypt all crypt entries* (=org-encrypt-entries=, =org-decrypt-entries=): every entry with the =crypt= tag.

The passphrase of every entry in this file is =example=. It is asked for once and kept in memory for ten minutes. While entries are decrypted, the copy of the file kept on this device is not updated (Settings → =org-crypt-disable-auto-save=); save the file after encrypting it again.

The =CRYPTKEY= property of the last entry names the key it is encrypted to; without it, =org-crypt-key= in Settings is used, and without a key, a passphrase. To open that entry, import =crypt-example-key.asc= under Settings → Encryption keys (its passphrase is also =example=), then choose *Decrypt entry*. It is a key for trying this out; do not use it for anything real.
