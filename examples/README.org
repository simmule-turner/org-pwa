#+TITLE: Examples
#+STARTUP: showall

One file per feature. Open one in the app, try it, and compare with the text already in the file. Where a file holds results (a table, a clock report, a calendar file, a list of matches), they are what Emacs 29.3 (Org 9.6.15) produced, and a test in this project checks that the app produces the same. The last section of a file lists where the app differs from Emacs; a file with no such section has none.

* How a result is checked
=tools/gen-*-oracle.mjs= run Emacs in batch mode and write what it produced; the matching test under =test/= holds the app to it. The files here were made the same way: written, run in Emacs, and the output kept. =test/babel-example.test.js= and =test/examples-emacs.test.js= run them in the app.
