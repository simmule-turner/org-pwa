** Reading the table
- =work&admin= is "and", =work|home= is "or", =+work-big= adds and removes a tag, ={^w}= matches tags by regexp.
- =LEVEL=2=, =TODO="NEXT"=, =CATEGORY="demo"=, =ITEM=, =TAGS=, =DEADLINE= and =SCHEDULED= are special properties; any other name (=Effort=, =SIZE=) is read from the heading's own properties.
- Text in double quotes is compared as text, a bare number as a number: =Effort>"1:00"= is a text comparison, =SIZE>1= a numeric one. A heading without the property compares as empty text or 0.
- After the last =/= come TODO keywords: =work/TODO=, =/NEXT|WAITING=, and =/!= for every task that is not done.
- Tags are inherited, so =@train= finds the headings under *Reading*.
- A query Org cannot read is not an error: it matches what is left over, as in Emacs.
