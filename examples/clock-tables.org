#+TITLE: Clock tables
#+STARTUP: showall

A cookbook for =#+BEGIN: clocktable=. In Emacs, =C-c C-c= on a block writes the table under it. In the app, *Clock* in the TODO view shows the same table read-only for a date range and a =maxlevel=. The table under each block here is what Emacs 29.3 (Org 9.6.15) wrote, and the app's table is the same, apart from the time in the caption, which is when it was made. The last section says where the two differ.

* The week, two levels deep
=:tstart= is included and =:tend= is not. A parent row includes its children.

#+BEGIN: clocktable :maxlevel 2 :scope file :tstart "2026-08-03" :tend "2026-08-10"
#+CAPTION: Clock summary at [2026-10-22 Thu 22:47]
| Headline     | Time   |      |
|--------------+--------+------|
| *Total time* | *7:30* |      |
|--------------+--------+------|
| Projects     | 7:30   |      |
| \_  Website  |        | 6:45 |
| \_  Taxes    |        | 0:45 |
#+END:

* Where the app differs from Emacs
- The app does not write the table into the file: it shows it in the TODO view. Open this file, pick *Clock*, and give the dates and the level above.
- Only =:maxlevel=, =:tstart=, =:tend= and the whole file (=:scope file=) are read. =:block=, =:step=, =:formula=, =:match=, =:link=, =:compact=, =:narrow=, =:tcolumns= and =:wstart= are not.
- The caption time is the time of the update, as Emacs writes it.
